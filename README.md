# 👤 Face Detection using OpenCV

A real-time Face Detection system built using Python and OpenCV that detects human faces from images and webcam video streams.

## 📌 Project Overview

This project uses Computer Vision techniques to detect human faces in real-time using a webcam or from static images.
The system leverages OpenCV's Haar Cascade Classifier, which is a pre-trained model for detecting frontal human faces.
Face detection is a key component in many real-world applications such as security systems, attendance tracking, and AI-based surveillance systems.

## ⚙️ How It Works

1. 📥 Capture input (image or webcam video)
2. 🎨 Convert frame to grayscale
3. 🔍 Apply Haar Cascade classifier
4. 📦 Detect face regions
5. 🟥 Draw bounding boxes around detected faces
